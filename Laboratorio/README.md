Autores: Sebastián Dávila · Cristian Durán · Luis Rojo.
Profesor de laboratorio: Manuel López.

Cada carpeta contiene una guía .tex autónoma, datos en CSV, parámetros en JSON y un diccionario de datos. Los valores conservan las instancias didácticas del adjunto; no se atribuyen a las organizaciones citadas.

OVERLEAF
Copie todo el .tex deseado en main.tex o súbalo como documento principal. Use pdfLaTeX. No combine los ocho preámbulos. No se necesitan archivos externos para compilar la guía.

PYTHON
Cree el notebook junto a la guía y mantenga datos/ en esa misma carpeta. Copie la celda inicial de la guía y complete los algoritmos. En Colab, suba o descomprima la carpeta del laboratorio y establezca esa carpeta como directorio de trabajo antes de usar las rutas relativas.

Se requieren Python 3, NumPy, pandas, Matplotlib y SciPy, instalados antes del bloque de 80 minutos. No se entregan algoritmos resueltos ni resultados óptimos dentro de los datasets.

CSV: UTF-8, coma como separador, punto decimal; sin índices de filas añadidos. Los JSON incluyen parámetros escalares y sus unidades están documentadas.
